AddUser2Shares
**************
Version 1.2 du 02-09-2018 (Voir l'historique à la fin du fichier).


DESCRIPTION :
=============
AddUser2Shares.cmd est un utilitaire qui permet l'ajout d'un utilisateur administrateur avec
mot de passe et qui ajoute les droits nécessaires aux différents partages disponiblent.
AddUser2Shares.cmd nécessite l'utilisation de l'utilitaire Microsoft subinacl.exe a placer
dans le sous dossier \Res
https://www.microsoft.com/en-us/download/confirmation.aspx?id=23510


UTILISATION AddUser2Shares :
===========================
Avant d'utiliser AddUser2Shares.cmd, éditez le et modifiez les paramètres de configuration ci-dessous :

          User=Nom_Utilisateur               ; Nom de l'utilisateur.
          Passwd=Mot_De_Passe                ; Mot de passe de l'utilisateur
          FullName=Nom_Complet_Utilisateur   ; Nom complet de l'utilisateur

Lancez le AddUser2Shares, puis choisissez l'action à réaliser.
